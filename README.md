#### Selected AI-native products

**[JobBoard](https://github.com/peterselj/JobBoard)** — a referral-first job-search CRM that treats
the job hunt as a weighted sales pipeline: it quantifies expected offers, prioritizes daily actions,
and keeps personal data private in-browser, used for my coaching clients. [Live demo](https://peterselj.github.io/JobBoard/)

**[DraftBoard](https://github.com/peterselj/DraftBoard)** — a live fantasy-auction decision tool that
separates intrinsic player value from market pricing, then adjusts recommendations for budget
inflation and positional scarcity as a draft unfolds. [Live demo](https://peterselj.github.io/DraftBoard/)

**[ShowdownOnline](https://github.com/peterselj/showdownOnline)** — a virtual tabletop for MLB
Showdown, built with my brother to bring a physical card game online with shared, synced game state.

**[Icon Highlighter](https://github.com/peterselj/iconhighlighter)** — a small, shipped utility that
adds a visual highlight ring to Doodle Board icons.

**[Party Invite](https://peterselj.github.io/invite/)** — a bespoke Mad Libs–style RSVP for the same
big, dumb birthday party I've thrown every year for a decade. Used to run it on Typeform until their
pricing got insufferable, so I built my own.
